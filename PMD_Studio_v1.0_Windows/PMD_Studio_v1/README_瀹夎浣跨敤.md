# PMD Studio v1.0 — Windows 本地测量控制台

**定位：** 针对现有大恒 MER2 单目相机＋iPad 的 PMD P0 实验系统。界面是 HTML，硬件控制、磁盘文件访问和形貌重建运行在本机 Python 服务中。不是 LabVIEW 原生 `.vi`。

## 1. 推荐安装位置

**将解压出来的整个 `PMD_Studio_v1` 文件夹放入已有项目目录：**

```text
D:\Optoelectronics\激光刀口法测曲率\Phase Measuring Deflectometry\PMD_P0_Starter\
├─ .venv\Scripts\python.exe     ← 已有虚拟环境
├─ gxipy\                      ← 已有大恒Python SDK（若此前放在项目根目录）
├─ measurements\                ← 原始实验数据，不会改变
└─ PMD_Studio_v1\
   ├─ install.bat
   ├─ start.bat
   ├─ start_demo.bat
   ├─ requirements.txt
   ├─ studio\                   ← Python后端
   ├─ web\                      ← 电脑与iPad界面
   └─ data\                     ← 自动创建，所有新测量/标定单元
```

如果放到其他位置，需要自己安装能导入 `gxipy` 的 Python 环境以及大恒Galaxy SDK。

### 安装

1. **停止**此前运行的 `serve_ipad.py --port 8000`，关闭 GalaxyView 或其他打开大恒相机的程序。不要结束 NI 的 8080 服务；本项目只使用 **8000**。
2. 双击 `install.bat`，等待出现 `Python dependencies OK`。它优先复用**上一级**已有的 `.venv`，不会覆盖 `measurements` 中的旧文件。
3. 双击 `start.bat`，保持命令行窗口运行。
4. 电脑浏览器打开 **http://127.0.0.1:8000/studio**。
5. iPad 与电脑连同一热点/局域网，在 iPad Safari 打开 **http://电脑的IPv4地址:8000/**。过去热点使用 `172.20.10.4`，如果电脑地址未改变，可用 **http://172.20.10.4:8000/**。建议将网页添加到主屏幕全屏运行，保持横屏。
6. 电脑点「设备 · 条纹」→「检查iPad连接」，应看到 `2360×1640` 和「已连接」；接着连接相机、开启预览。

**如果 Windows 防火墙拦截：** 仅为受信任的专用网络允许 Python 入站 TCP 8000；不要直接暴露在公共网络。当前服务没有登录认证。

> 实际设备软件触发与 iPad 全屏时序需在用户 Windows 实机上再验证；这里没有连接实物硬件。`start_demo.bat` 仅测试交互，不可将模拟数据视为真实测量。

## 2. 四个界面

**设备 · 条纹：** 显示黑/白图、X/Y 方向4周期条纹；可改变频率列表（必须包含1和4）、平均灰度、调制度、屏幕物理尺寸，并检测iPad分辨率。设置屏幕尺寸时以iPad实际有效显示区域的毫米尺寸为准；不要在同一套几何标定对应的光路中旋转iPad或随意修改屏幕尺寸。

**相机：** 连接/断开大恒相机，设置曝光 µs，实时预览（网页内流式刷新，**不是嵌入GalaxyView窗口**），拍摄单张测试图。相机由一个 Python 进程拥有，预览和采集互斥。

**采集 · 结果：** 为**每次实验**创建独立测量单元，填名称、气压和备注，并绑定一个已完成的标定。创建时将几何参数**复制一份不可变的快照**到该单元，后续即使更换标定也不会自动改写旧结果。可自动采集、从 ZIP 导入之前的原始图像、1+4周期相位解码、按指定参考高度重建、去最佳拟合平面、球面拟合、导出 CSV/NPZ/JSON。

**标定：** 新建标定；可导入内参 NPZ，拍/上传固定参考平面的棋盘格（默认9×6内角点、格长4 mm），求参考平面，再自动采/导入标准平面镜相移图，计算iPad位姿；最后将该标定锁定，供任意测量重复使用。**可直接导入已验证的 `system_geometry_new.npz`**，跳过重新标定。

## 3. 用上次实验直接起步（最省事）

当前用户已经有新光路的文件：

```text
...\PMD_P0_Starter\measurements\new_calibration\geometry_new\system_geometry_new.npz
```

1. 「标定」→ 新建标定（例如`新光路 · 2026-11`）。
2. 选择刚建好的标定，在「已有标定快速导入」点击「导入完整几何NPZ并锁定」，选择上述 `system_geometry_new.npz`。
3. 「采集 · 结果」→ 新建测量，选用该标定，填写`气动镜 · 不充气` / `0 kPa`。
4. 「相机」→ 连接、预览、调整曝光、停止预览。
5. 确保iPad已连接。回「采集 · 结果」点「自动采集」。采集时会自动关闭预览、按图案ACK逐张触发相机，默认图案设置为1、4、16周期四步相移（**共26张**），每张图像保存到本次记录的 `raw/`。
6. 完成后点「相位解码」，检查Mask，再点「重建 · 拟合」。
7. 查看二维去平面形貌、三维形貌和球面残差，以及PV/RMS。结果和原始照片都保存在同一单元中。

如果想重新处理以前的球面镜测量，先在Windows资源管理器把原来的 `new_mirror_run02` 文件夹压缩成 ZIP，创建一个新的测量单元，点击「导入26张ZIP」，然后解码/重建；ZIP里允许带上原目录层级，仅提取标准相移 `.png` 文件。

## 4. 全新的几何标定顺序

1. **保持相机、镜头、iPad完全固定。** 相机内参 `K,dist` 可从已保存的 `.npz` 导入，默认不强制重做相机内参。
2. 固定一个参考平面，把棋盘格**印刷面**定位在标准平面镜**反射面**所在的实际几何平面，拍摄3—6张；棋盘格图像之间不应改变参考平面。也可导入此前拍的图片。
3. 点击「计算参考平面」，程序根据重复照片的平面距离/法向一致性剔除明显离群项，同时显示每张PnP RMS；**5 px的PnP误差不等于可靠的标定**。
4. 拿走棋盘格，放平面镜；反射面必须与棋盘格所在平面共面或具备已知位姿修正，否则不能拿棋盘格参数替代真实镜面参数。
5. 点「采集平面镜条纹」，完成后点「计算并锁定标定」。这会计算虚拟屏幕的PnP位姿，再关于参考平面镜像回真实iPad位置。保存标定、残差及参与拟合的质量信息。
6. 如果更换相机、iPad或其姿态，**旧几何标定立即失效**，应新建标定记录。

## 5. 数据组织

```text
PMD_Studio_v1/data/
├─ calibrations/
│  └─ cal_.../
│     ├─ record.json           名称、日期、条件、参考平面、质量指标
│     ├─ intrinsics.npz        K,dist（若导入）
│     ├─ board/                棋盘格照片
│     ├─ plane.json            多照片PnP和离群项
│     ├─ flat/                 平面镜原始相移图
│     ├─ flat_decoded/         平面镜相位解码
│     ├─ geometry.npz          屏幕位姿与参考平面；一旦就绪锁定
│     └─ geometry_result.json  屏幕标定质量指标
└─ measurements/
   └─ run_.../
      ├─ record.json                名称、压力、备注、标定ID及测量状态
      ├─ calibration_snapshot/
      │  ├─ geometry.npz           该次测量专属标定快照
      │  └─ source.json
      ├─ raw/                     完整原始PNG和capture.json
      ├─ decoded/                 screen_uv.npz、mask.png、相位图
      └─ reconstruction/          shape.npz、CSV、RMS/PV、球面参数及图片
```

新单元不自动覆盖旧单元；在网页中点击「打开本次数据文件夹」即可用 Windows 资源管理器查看全部文件；测量失败时保留已拍照片供诊断。**不要把 `data/` 提交到公开代码仓库或随意清空。** 可定期整个文件夹备份。

## 6. 技术边界

- 这是**单目PMD P0近似重建**：绝对高度/曲率半径依赖参考平面、屏幕位姿及手动给定的`中心高度`。当前 `RMS`、`PV` 和拟合球面残差不是仪器经计量溯源的精度声明。
- iPad要求完整显示灰度条纹；如果条纹16周期调制度过低，软件只使用**1、4周期**解码，16周期原图保留供后续开发。采集频率列表可以为`1,4`（18张）或者`1,4,16`（26张）。
- 软件假设 **MONO8** 单通道图像。若相机输出16 bit，后端会降为8 bit，并提示你优先使用兼容的Mono8配置。高精度灰度/曝光时序需要在实机验证。
- 相机实时预览由软件触发后发送压缩JPEG，不访问厂家GalaxyView程序窗口。自动采集保存无损PNG。
- 软件不是公网上的多用户Web服务；目前没有用户登录，**只能在受信任的局域网运行**。
- 相机SDK独立于pip，必须保留已经成功运行的Galaxy SDK/gxipy环境。电脑无需保持互联网连接即可运行服务和条纹图，但**首次安装Python依赖需要网络**。
- 没有自动压力传感器；当前`压力`是手工填写的元数据。

## 7. 排错

| 现象 | 检查 |
|---|---|
| `Address already in use` | 先停止旧`serve_ipad.py --port 8000`，不要同时运行两个8000服务；8080是NI占用，无需动它 |
| `gxipy`找不到 | 确保使用旧PMD工程的`.venv`，且`gxipy`文件夹仍位于`PMD_P0_Starter`根目录 |
| 相机连接失败 | 关闭GalaxyView和其他采集脚本；检查Galaxy SDK、USB、相机供电 |
| iPad离线 | iPad与电脑同局域网，电脑用`ipconfig`查IPv4，Safari打开电脑IP:8000，查看防火墙 |
| iPad画布不为2360×1640 | 恢复iPad横屏、主屏幕全屏；屏幕像素尺寸要与本次iPad环境一致 |
| 采集黑白图错位 | 确认使用新软件的**触发采集**而非旧`acquire.py`连续读帧方式；检查ACK后是否确实换图 |
| Mask面积小 | 检查iPad是否完整覆盖反射区域、曝光是否过曝、16周期条纹是否低调制；软件解码只需1+4 |
| 求解屏幕位姿失败 | 检查棋盘格与平面镜共面、角点识别、相移图完整且同光路、iPad物理尺寸 |
| 参考半径偏差大 | 验证相机/屏幕没有被移动、几何标定准确、中心深度假设，并用独立已知镜面验证 |

**本部署包不是静态HTML**，本机Python服务必须保持运行。关闭命令行窗口就会停止相机控制和iPad条纹服务。
