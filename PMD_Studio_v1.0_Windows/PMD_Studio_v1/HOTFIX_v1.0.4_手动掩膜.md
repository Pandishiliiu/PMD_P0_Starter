# PMD Studio v1.0.4：测量工作区手动掩膜

## 用途

适用于气动镜等样品：图像中实际有效反射区位于中央，外围镜框、反光边圈、支撑结构也有亮度和条纹响应，自动亮度/调制度阈值无法准确区分实际测量面。

**Mask 是每次测量独有的数据，不修改系统标定，也不修改原始 26 张照片。**

## 安装

1. 停止 PMD Studio 服务（运行窗口按 Ctrl+C）。
2. 解压此补丁，将 `PMD_Studio_v1` 文件夹覆盖到当前程序所在位置（例如 `PMD_Studio_v1.0_Windows` 目录），选择合并/覆盖同名文件。
3. 原有的 `data`、`calibrations`、`measurements` 不需要移动、删除或覆盖。
4. 重新启动 `start.bat`，在电脑浏览器按 `Ctrl+F5` 强制刷新。版本栏显示 `v1.0.4`。
5. iPad 页面没有改动，iPad 不需要重新加入主屏幕，也不需要重新标定。

## 操作

进入 **采集 · 结果**，选中一条**已采集/已导入26张相移照片的测量**，展开 **手动有效区域（Mask）**。程序自动读取该条测量的 `white.png` 并显示。

- **椭圆拖拽**：在白图上从一个角拖到另一角，画出轴向椭圆。
- **多边形逐点**：沿真实工作面内部边界点选，按 `闭合多边形`。适用于轻微倾斜的椭圆或不规则边界。
- **边缘内缩**：指定**全分辨率相机像素**（非缩小后的网页预览像素）。初次建议 `15–30 px`，可根据图像实际边缘调整。
- 点击 **保存掩膜**，再点击 **相位解码** → **重建 · 拟合**。
- 点击 **查看掩膜PNG**，能单独检查最终黑白工作区。
- 点击 **取消手动掩膜**，恢复纯自动 Mask。

已经处理过的测量也可以补画掩膜，不必重新采集。每次修改/撤销掩膜时，之前的 `decoded`/`reconstruction` 会被移动到该测量的 `history/` 中，以免覆盖已有结果；重新点击解码、重建即可。

## 数学逻辑

```
最终相位有效Mask = 手动工作区 ∩ 白黑亮度有效区 ∩ X相位调制度/展开有效区 ∩ Y相位调制度/展开有效区
```

不能用手工圈选强行填补原本无相位或低调制度区域，不能把轮廓之外的反光边圈混进积分、曲面拟合、PV/RMS统计。

## 文件

每条测量数据单元目录中新增：

- `roi.json`：编辑模式、归一化顶点和边缘内缩像素，可重复编辑；
- `roi_mask.png`：与原始相移图相同分辨率的二值图（255保留，0剔除）；
- `history/`：改变Mask前的旧相位/形貌结果归档。

## 注意

1. Mask 只限制用于计算的镜面范围，**不会改善因相机内参、iPad位姿、未知深度造成的系统误差**。
2. 不同气压状态的 PV/RMS 比较应使用相同物理范围；对不同图像手绘的Mask可能并不严格对应同一物理区域，严格定量比较还需空间配准与共同有效区。
3. 包内测试使用模拟数据验证，不代表已经在现场大恒相机上完成硬件联调。
