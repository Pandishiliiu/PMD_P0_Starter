# PMD Studio v1.0.6：相机内参标定

本版本仅增加“标定 → 相机内参”的**采集、检测、求解、查看、导出**功能。原有 iPad 条纹、相机预览、26 张图采集、平面镜标定、手动 Mask、形貌重建和双向曲率分析不改算法。**本包未经你现场的大恒相机实机联调**；已通过合成棋盘图/接口及原有模拟流程测试。

## 升级（不会删除 data）

1. 退出 Studio 服务（启动窗口 `Ctrl+C`）。
2. 备份当前 `PMD_Studio_v1` 文件夹，尤其是 `data/`。
3. 解压补丁包，把其中 `PMD_Studio_v1` **合并到当前同名目录**，覆盖同名代码文件。不要删除原来的 `data` 目录。若使用完整包，则复制完整包的程序代码，**保留原 data**。
4. 在原目录双击 `start.bat`，访问 `http://127.0.0.1:8000/studio`，按 `Ctrl+F5` 强制刷新。顶部显示 `v1.0.6`。
5. 不需重新安装依赖。仍使用原项目 `.venv` 和 `gxipy`。

如果使用的是之前讨论的 Windows 布局，原位置大致为：

`D:\Optoelectronics\激光刀口法测曲率\Phase Measuring Deflectometry\PMD_P0_Starter\PMD_Studio_v1.0_Windows\PMD_Studio_v1`

## 使用：标定已有商用标定板的相机内参

1. 「相机」连接大恒 MER2 相机，设置曝光时间并检查画面清晰。**相机镜头焦距、对焦、光圈、相机分辨率在本次标定与后续测量时应尽量一致。**
2. 「标定」→「新建标定」，如 `2026-11-16_新内参`。新建标定时的 `棋盘内角点 X/Y、单格尺寸` 是**下一步的参考平面**参数；可以与内参标定板不同。
3. 选择新标定，在「1 · 相机内参」展开「采集与计算内参」。选择板型和厂家印刷规格：
   - **棋盘格**：填 **内角点数**（不是黑白方格个数），以及单格边长 mm。
   - **对称圆点阵**：填横/纵圆心数，以及相邻点中心间距 mm。
   - **非对称圆点阵**：按 OpenCV 标准交错点阵定义填写横/纵点数和相邻行间距 mm；不同厂家对 pitch 定义可能不同，先核对实际标记/尺寸，不确定时不要使用非对称选项。
   - **ChArUco、AprilTag 板不在此版本支持范围内**，不要当普通棋盘格导入。
4. 点击「拍摄一张」，每拍一张**移动、旋转、倾斜标定板**再拍下一张。建议 **18–25 张**，板占画面较大但所有点清晰可见，至少覆盖画面中间、四周，前后距离和 15°–35° 左右倾角均有变化。**与参考平面标定不同，此时应主动改变棋盘姿态！** 可以选择「上传已有多角度照片」。
5. 点击「计算内参」。计算结果显示全局重投影 RMS、`fx fy cx cy`、畸变系数、每张是否识别/采用以及警告信息。点击「检查角点预览」查看叠加。即便 RMS 很小，若警告提示倾角跨度不足、覆盖太集中、畸变异常等，也需要重新采样。
6. 点击「下载内参 NPZ」可导出 `camera_intrinsics.npz`。内参也自动保存到当前标定记录中的 `intrinsics.npz`，随后直接用于「2 · 棋盘格参考平面」和「4 · 屏幕位姿」。**不必重复导入**。
7. 对下一次光路标定，可新建标定后点击原有的「导入内参 NPZ」，选刚下载的 `camera_intrinsics.npz`，然后继续参考平面/平面镜标定。

## 数据结构

每个标定 ID 下有：

```
data/calibrations/cal_.../
  record.json
  intrinsic_images/       # 原始标定板照片（不覆盖）
  intrinsic_corners/      # 检测到的角点叠加预览
  intrinsic_result.json   # RMS、每张误差、规格、警告
  intrinsics.npz          # K、dist、image_width/height、rms_px
  board/                  # 原有参考平面拍摄，不变
  flat/                   # 原有平面镜拍摄，不变
  geometry.npz            # 原有完整系统几何，不变
```

原来的标定和测量单元不会被改动；已锁定标定只能下载内参，不能重新求解（需要新建标定记录）。

## 注意精度

* 全局 RMS 是角点的**重投影误差**，不是 PMD 形貌测量误差。
* 标定结果依赖图像分辨率以及对焦/镜头状态。请在 `image_size` 中确认新板与实际 PMD 拍摄分辨率一致。
* 不要用商用板的标称精度替代相机标定质量验证；若方格尺寸定义错误，会影响下一阶段参考平面/屏幕尺度。
* 棋盘格图像如果特别小、几乎全部正视，可能出现低 RMS 但奇异的畸变参数；本工具会给出部分诊断警告，但无法保证每组真实采集都可标定成功。
* 有 `K,dist` 不代表现有参考平面/iPad几何自动更新；更换内参后必须使用同一新标定记录重新计算参考平面和屏幕位姿，不能将新内参直接与已锁定的旧外参混用。
